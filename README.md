# Python Password Strength Checker

A beginner-friendly local Python security project.

## Features
- Checks password length and character variety
- Provides suggestions for improving password strength
- Uses getpass to hide password input
- Does not send passwords to a server
- Does not save passwords to a file

## Requirements
- Python 3

## Run
python checker.py

## Security note
Use test passwords. This is a basic educational checker,
not a guarantee that a password is secure.
